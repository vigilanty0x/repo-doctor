# Safety and privacy

The default command inspects executable availability and version output on the current machine. It does not transmit results. Version strings and executable paths can still reveal workstation details, so review a real report before sharing it.

For documentation, demonstrations, tests, screenshots, and bug reports, use synthetic fixtures. Fixture executable paths use `/synthetic/bin/` and carry no account, host, or daemon dependency.

The tool is diagnostic only. A missing tool explanation is not permission to install it, and an execution blockage is not permission to bypass access controls. An open circuit makes degraded state visible while reducing repeated work.
